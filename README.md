# demo-web

Premium real estate and architecture portfolio built with Next.js 16, React, Tailwind CSS 4, and Framer Motion.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Quality checks

```bash
npx tsc --noEmit
npm run lint
npm run build
```

The app is deployed to Vercel. Connect the GitHub repository in Vercel to enable automatic deployments on each push.
